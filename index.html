About

Deuterium Client is an advanced, so called "ghost client" for Minecraft version 1.8.9, based on Minecraft Forge. Deuterium is built for giving yourself various utilities, all while keeping the experience lightweight and clean. We focus on improving your gameplay without drawing attention to it.

WARNING: Use this client at your own risk, ghost clients are not fully undetectable. The Deuterium development team is not responsible for any damage you cause to your Minecraft accounts.

straight-forward

Deuterium is built to be straightforward and easy to understand. Each module is designed to be simple to use while staying effective.

open-source

Deuterium is completely open-source and hosted on GitHub. No hidden trackers, no sneaky miners, and no code you can't inspect.

easy-to-use advanced gui

The Deuterium GUI is clean, highly customizable, and built to feel familiar from the very first launch.

Download


Deuterium Client is available to download from this site or our GitHub. If you want a quick install, use the installer below or grab the jar for a manual setup.

To install Deuterium automatically, open the installer, choose the version you want, and launch a Forge 1.8.9 profile.

Don't have Forge installed? Download it here!

To install Deuterium manually, place the jar file in your /.minecraft/mods folder and run a Forge 1.8.9 version.
